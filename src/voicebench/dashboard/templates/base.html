Benchmark pages are a read-only view of the run files committed under results/. Every number on them is computed from those files; nothing is re-run or re-scored here.

The live console runs on the free tiers of Vercel (this page and /api/analyze) and Hugging Face (model downloads). Audio is processed in your browser and never uploaded; only the text transcript, and a reference sentence if you type one, is sent to /api/analyze, which does not store or log it.
