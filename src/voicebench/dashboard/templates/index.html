01 Live test console

Speak, upload or replay a clip, and score it live

Whisper runs in your browser with transformers.js (onnxruntime-web). The transcript then goes through this project's own intent / slot matcher and WER code on the server.

This is a fresh run, not the stored baseline. The console uses OpenAI Whisper weights converted to ONNX (q8) and run by onnxruntime-web in your browser. The benchmark's stored runs used faster-whisper (CTranslate2, int8) on a server CPU, so a live result is a new measurement on your device. It never replaces the stored {% if fa %}{{ fa.matrix.all.all.ok }}/{{ fa.matrix.all.all.n }}{% endif %} baseline. Expect weak Hindi accuracy from tiny and base. Even the stored small baseline passes {% if fa %}{{ fa.matrix.hi.all.ok }}/{{ fa.matrix.hi.all.n }}{% else %}few{% endif %} Hindi scenarios with auto-detect (see the README's "What failed"){% if browser_meas %}{% set brows = browser_meas.rows | selectattr("load_ms") | list %}{% if brows and (brows | selectattr("corpus_wer", "gt", 1) | list | length) == brows | length %}, and on {{ brows[0].n }} human Hindi clips every browser model measured here had a corpus WER above 1 (table below the console){% endif %}{% endif %}.
